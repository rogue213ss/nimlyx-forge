## 1. ROOT CAUSE ANALYSIS & FIXES

### 1.1 Source Diversity Failure (0 DDG Sources)
**Root Cause**: DuckDuckGo's main HTML endpoint (`html.duckduckgo.com`) began actively returning `HTTP 202` bot-protection challenges against `requests`, which `res.raise_for_status()` caught as an error, silently abandoning all DDG search discovery and falling back solely to Wikipedia.
**Fix**: Migrated `DuckDuckGoDiscoveryProvider` to use `lite.duckduckgo.com/lite/` via `POST`, paired with a clean `User-Agent`. It now successfully scrapes results natively, restoring full TIER_1 and TIER_2 discovery capability without requiring external packages.

### 1.2 Claim Explosion (1,566 Claims)
**Root Cause**: `AdvancedHeuristicExtractor` was blindly splitting Wikipedia's massive pages by periods and matching keywords anywhere. This ingested navigation sidebars, reference brackets (`[12]`), footers, and non-factual "fluff" sentences just because they contained words like "team" or "patch".
**Fix**: Implemented strict semantic heuristics. To be extracted, a sentence must now:
1. Be between 30 and 300 characters.
2. Start with a capital letter or digit and end in proper punctuation.
3. Have citations (e.g., `[citation needed]`) scrubbed.
4. **CRITICAL**: The sentence must contain either the exact target entity name, an explicit year (`19XX/20XX`), or specific numeric data. If none of these three exist, it is discarded as non-factual boilerplate.

### 1.3 Scope Classification Aggressiveness
**Root Cause**: The scope classifier required exact word-for-word inclusion of the topic.
**Fix**: Replaced with entity-aware heuristics. It now extracts the core `game_name` and checks for sequel markers ("2", "II") to mark them as `RELATED`, while allowing variations like "The Witcher 3 review" to correctly flag as `PRIMARY` rather than `REJECTED`. `REJECTED` sources are now strictly ignored by `retrieve_source` and `process_source_claims`, saving significant bandwidth.
