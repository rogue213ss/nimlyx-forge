## 1. Documentation & Architecture

Phase 6 implements the **Semantic Footage Selection, Intent Mapping & Clip Planning** layer. 

**State Machines:**
*   `AssetState` (V1-V5): Represents the physical status of the media (e.g. `CANDIDATE` -> `DOWNLOADED`).
*   `SelectionStatus` (V6): Represents the editorial candidate status (e.g. `UNSCORED`, `AUTO_SELECTED`, `REJECTED`).
*   *Crucial Isolation*: V6 does not automatically approve media for downloading. An `AUTO_SELECTED` mapping remains a `CANDIDATE` until explicit human interaction transitions it to `APPROVED_FOR_ACQUISITION`. 

**Scoring Architecture:**
1.  **V4 Base Relevance**: Initial discovery score.
2.  **Signals (+)**: Preferred Content Types (+15), Preferred Channels (+20), Preferred Year (+10), Official Source (+10).
3.  **Penalties (-)**: Avoided Content Types (-20), Mismatched Year (-10), Shorts (-25).
4.  **Clamping**: Normalizes all output strictly to the `[0.0, 100.0]` range.
5.  **Reasoning**: Emits canonical JSON (`separators=(',', ':')`, sorted keys) detailing exact signals used.

**Confidence Thresholds:**
*   `80 - 100`: HIGH
*   `60 - 79`: MEDIUM
*   `40 - 59`: LOW
*   `0 - 39`: REJECTED

**Clip Planning Rules:**
The planner evaluates user-supplied timestamps. It rigorously validates:
*   `duration >= 2.0`
*   `duration <= 60.0`
*   `start < end`
*   `end <= source_duration`
If invalid, it explicitly rejects generating a clip and yields `UNKNOWN` confidence with a detailed string reason explaining the exact failure limit.
