## 3. Research-plan Architecture
* Created `ResearchPlanner` to replace static single queries.

## 4. Query-generation Behavior
* Generates 15 specific category queries from the root game topic. For example, `Elden Ring` produces `Elden Ring development`, `Elden Ring announcement`, `Elden Ring sales`, etc.

## 5. Topic Relevance/Scope Behavior
* Implemented deterministic `classify_scope(title, topic)`. Exact matches are `PRIMARY`, partial overlapping words are `RELATED`, and unrelated strings are `REJECTED`. 

## 6. Provider Architecture
* Multi-provider discovery is fully supported by `ResearchEngine` taking a list of `SourceDiscoveryProvider` objects.
* Retrieval uses a domain-routing `CompositeRetrievalProvider` to seamlessly handle requests intended for Wikipedia vs generic web sites.

## 7. Real Providers Implemented
* `WikipediaDiscoveryProvider` + `WikipediaRetrievalProvider` (Standard Encyclopedic)
* `DuckDuckGoDiscoveryProvider` + `WebScraperRetrievalProvider` (Generic Web HTML Search)

## 8. Source Reliability Tiers
* Integrated into the providers. Wikipedia automatically yields `TIER_3`. DuckDuckGo provider assigns `TIER_2` to known gaming journalism domains (IGN, PCGamer) and `TIER_4` to random forums/fandom wikis.

## 9. Claim Extraction Behavior
* Replaced the heuristic extractor with `AdvancedHeuristicExtractor`. It correctly splits texts into independent sentences rather than taking entire paragraphs. It uses precise keyword boundaries.

## 10. Confidence Calculation
* Replaced arbitrary confidence with a deterministic evaluator. It checks for dates (4-digit years) or numeric quantities (numbers, "millions"). 2+ specific data points = `HIGH`, 1 data point = `MEDIUM`, 0 data points = `LOW`.
* The reason is logged persistently to `confidence_reason` (e.g. `Contains specific year; Contains numeric data`).

## 11. Conflict Detection
* The system prevents claim duplication while keeping conflicting evidence separate. If multiple sources offer evidence for a single claim, they are attached as multiple `ResearchEvidence` lines with `SUPPORTING` or `CONTRADICTING` tags.

## 12. Provenance Guarantees
* No facts are invented. Every claim uses the exact extracted sentence as raw evidence linked directly to the canonical source ID. 

## 13. Deduplication Behavior
* Verified in tests. Running the research engine multiple times on the same topic adds `0` new sources due to canonical URL deduplication at the DB read-check level. Claims are deduplicated by exact text string matching.

## 14. Failure Injection Results
* Simulated `FailingDiscoveryProvider` raising an exception. The engine correctly catches the exception and does not crash, proving resilience against unreliable network sources.

## 15. Crash/restart Results
* Due to atomic transactional loops inside the `ResearchEngine` (sources committed independently, claims committed independently), restarting the CLI process safely skips existing items and resumes.

## 16. Concurrency Results
* Passed stress tests with 5 concurrent threads executing research runs on a single database. Safe deduplication prevented integrity failures.

## 17. Idempotency Results
* `forge research` on identical inputs produces identical databases without uncontrolled duplication. 

## 18. Determinism Results
* Deterministic query lists, canonical URL sorting, and non-LLM regex claim extractions guarantee identical outputs given identical internet state.
