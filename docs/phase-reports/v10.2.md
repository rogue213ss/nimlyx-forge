# NIMLYX FORGE - V10.2 LIVE GEMINI RESILIENCE VALIDATION

## 1. Payload Size Baseline (Root Cause Analysis)
* During V10.1, the Gemini API returned 503 UNAVAILABLE when llm-script-build was run.
* In V10.2, we established a payload-size baseline by sending progressively larger requests (1, 2, 5, 10, 18 briefs).
* Finding: The API rejection was NOT due to payload size limits or model timeouts. Instead, the testing environment's gemini-3.8-flash model is strictly gated by a Free Tier Quota of 20 requests per DAY (GenerateRequestsPerDayPerProjectPerModel-FreeTier).
* Because the V10 LLMScriptWriter already chunks processing sequentially by NarrationSegment, a full 18-segment StoryRun consumes 18 API requests instantly, completely exhausting the daily quota and resulting in a 429 RESOURCE_EXHAUSTED (or 503 UNAVAILABLE under certain high-load free tier edge cases).
* Conclusion on Chunking: Chunking is already properly implemented at the segment level. No further chunking logic is needed in LLMScriptWriter.

## 2. Harden Retry Handling
* Implemented robust exponential backoff in GeminiProvider with maximum retry limits (5 attempts) and bounded delays (base_delay * 2^attempt).
* Configured the retry to ONLY trigger on transient HTTP errors (429, 500, 502, 503, and timeouts). Permanent errors (e.g., 400 Bad Request, auth failures) immediately fail and do not enter a loop.
* Implemented Python logging to gracefully warn upon transient failures and log exact delays.

## 3. Extractor Heuristic Fix (Fallout NV)
* Bug: AdvancedHeuristicExtractor was previously performing a strict case, whitespace, and punctuation exact substring match on the target topic. Queries like "Fallout New Vegas" failed to match sentences containing "Fallout: New Vegas".
* Fix: Upgraded the topic matching logic to normalize strings by stripping non-alphanumeric punctuation and collapsing whitespace before comparison.
* Validation: Wrote and passed provider-level unit tests (backend/tests/v10_2_test_extractor.py) proving robust matching against case, punctuation, and unrelated game titles (e.g. successfully rejecting "Fallout 3").
